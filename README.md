# 凌栖预研 / Sojourn Research

> 凌栖/Sojourn项目开创性预研仓库——各方向前沿探索、理论研究、设计灵感库，产出供各开发任务参考。

## 定位

本仓库是**纯研究/文档仓库**，不修改任何现有代码仓库。所有预研成果供各开发任务在下一阶段参考实施。

**原则：保持当前任务稳定，新方向发展在下阶段进行。**

## 各方向职责

### 灵火Ember预研
- 追踪AI认知架构、大模型推理、认知科学最新发展
- 查找有价值的研究方向（如：预测编码、全局工作空间理论、主动推理、情感计算等）
- 发展理论，可借用当前Ember系统验证假设
- 产出：技术追踪报告、研究方向提案、理论分析文档

### 建木Arboreus预研
- 追踪游戏引擎、世界生成、程序化内容、模拟仿真最新发展
- 查找有价值的研究方向（如：生态模拟、社会模拟、涌现行为、无限世界生成等）
- 发展理论，可借用当前Arboreus系统验证
- 产出：技术追踪报告、研究方向提案、理论分析文档

### 游戏设计预研
- 大量仔细学习历史、文化、哲学
- 建立结构化数据库（人物、事件、概念、象征、神话原型等）
- 建立信息关联网络（跨领域联想、隐喻映射、主题串联）
- 建立想象和联想机制，发展新的设计灵感
- 产出：研究笔记、数据库条目、设计灵感集、联想图谱

### 测试预研
- 学习测试理论、自动化测试、性能测试相关文档
- 分析当前测试体系的不足
- 提出改进建议（测试策略、覆盖率、性能基准等）

### 管理预研
- 学习项目管理、敏捷开发、团队协作相关文档
- 分析当前管理体系的不足
- 提出改进建议（流程优化、工具改进、协作机制等）

## 工作规范

1. **只读现有仓库**：预研任务只读取现有仓库的代码和文档用于分析，不做任何修改
2. **只写本仓库**：所有产出写入 D:\Sojourn\research\ 对应目录
3. **建档同步**：每轮产出必须commit并push到本仓库
4. **参考价值**：产出需有明确的参考价值，供各开发任务在下一阶段查看
5. **不干扰当前开发**：预研方向的实际实现留待下一阶段，当前阶段只做研究和文档

## 产出格式

每轮产出至少包含：
- 研究笔记（Markdown）
- 关键发现摘要
- 对现有系统的参考建议（如有）
- 下一步研究方向

## 与其他任务的关系

- 各开发任务可自由查阅本仓库的研究成果
- 预研任务不向开发任务下发指令，只提供参考
- 监控任务负责协调预研成果与开发计划的对接
