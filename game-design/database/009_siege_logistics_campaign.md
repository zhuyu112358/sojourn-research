## 一、核心定位

围城战（Siege warfare）是战争中最古老也最持久的形式之一。与野战的速决不同，围城战是**时间、资源和意志的消耗竞赛**。孙子说"兵贵胜，不贵久"，但围城战恰恰是"久"的艺术——攻城方需要在资源耗尽前攻破城池，守城方需要在救援到来前坚守。

后勤（Logistics）则是战争的隐形支柱。拿破仑说"军队是靠肚子行军的"，克劳塞维茨说"后勤是战争的第五个要素"。大多数战争的胜负不是在战场上决定的，而是在补给线上决定的。

本条目梳理围城战和后勤战的历史经验，为战策的RTS设计提供持久战和资源战的灵感。

## 二、围城战的历史演变

### 2.1 古代：攻城器械与防御工事的竞赛

**特洛伊围城（约公元前1200年）**
- 希腊联军围攻特洛伊十年，最终以木马计破城
- 核心教训：城墙坚固的城市无法靠强攻夺取，需要计谋和长期封锁
- **游戏映射**：坚城需要特殊手段（攻城器械、计谋、内部颠覆），不能靠普通攻击

**巴比伦围城（公元前539年，居鲁士大帝）**
- 波斯军队引幼发拉底河水，从河床入城
- 核心教训：城市的水路也是弱点
- **游戏映射**：地图上的河流/水道可以被利用为进攻路线

**叙拉古围城（公元前214-212年，罗马vs迦太基+叙拉古）**
- 阿基米德设计的防御器械（抛石机、抓钩、聚光镜）让罗马人损失惨重
- 最终罗马人趁叙拉古人节日狂欢时偷袭得手
- 核心教训：技术防御可以极大改变攻防平衡，但人的松懈是最大弱点
- **游戏映射**：防御科技树可以极大增强守城能力，但"节日/松懈"事件可以成为破局点

### 2.2 中世纪：城堡攻防的黄金时代

**十字军东征中的围城战**
- 安条克围城（1097-1098）：十字军围城8个月，自身几乎饿死，最终靠内应破城
- 阿卡围城（1189-1191）：近两年的围城，双方都经历了补给危机
- 核心教训：围城者自身也会被"反包围"——守城方的援军可以切断围城者的补给

**君士坦丁堡围城（1453年）**
- 奥斯曼帝国用巨型乌尔班大炮轰击狄奥多西城墙
- 守军仅7000人对抗8万奥斯曼军，坚守53天
- 最终因一扇小门（凯尔科波特门）未关而被突破
- 核心教训：火炮的出现终结了城墙时代；最小的疏忽可以导致全局崩溃
- **游戏映射**：攻城武器（火炮）可以改变攻防平衡；防御方的"疏忽"（如未关门）可以设计为随机事件或玩家操作失误的惩罚

### 2.3 近代：堑壕战与总体战

**凡尔登战役（1916年）**
- 德军战略："让法国人流尽鲜血"——选择凡尔登这个法国不愿放弃的据点，消耗法军有生力量
- 10个月，双方伤亡约70万人
- 核心教训：围城/消耗战的目标可以不是夺取土地，而是消耗对方人力
- **游戏映射**："消耗战"胜利条件——不是摧毁基地，而是将对方的兵力/资源消耗到阈值以下

**列宁格勒围城（1941-1944年）**
- 德军围困列宁格勒872天，城内约100万人死于饥饿和轰炸
- 拉多加湖的"生命之路"（冬季冰面运输）是唯一补给线
- 核心教训：平民的承受力是围城战的关键因素；补给线哪怕极其脆弱也能维持抵抗意志
- **游戏映射**：围城战中"平民士气"是关键指标；脆弱的补给线（如冰路）可以维持最低限度的抵抗

**斯大林格勒保卫战（1942-1943年）**
- 城市废墟中的逐屋争夺，"鼠战"（Rattenkrieg）
- 德军占领了城市的90%，但始终无法完全控制
- 最终苏军从城市南北两翼发动钳形攻势（天王星行动），包围德军第6集团军
- 核心教训：城市战中，占领土地不等于控制城市；围城者可能反过来被围
- **游戏映射**：城市/建筑地形中，占领建筑不等于完全控制，需要清剿；围城方需要注意自身侧翼

## 三、围城战的战略逻辑

### 3.1 围城战的三重消耗

围城战是三方消耗竞赛：
1. **攻城方的消耗**：兵力、补给、时间、士气
2. **守城方的消耗**：粮食、水源、弹药、兵力、士气
3. **双方的"意志消耗"**：谁先失去继续战斗的意愿

> 孙子："攻城之法，为不得已。修橹轒辒，具器械，三月而后成；距堙，又三月而后已。将不胜其忿而蚁附之，杀士卒三分之一而城不拔者，此攻之灾也。"

### 3.2 围城战的破局方式

| 破局方式 | 历史案例 | 游戏映射 |
|---------|---------|---------|
| 强攻 | 君士坦丁堡（大炮） | 攻城武器/特殊技能强行突破 |
| 封锁/断粮 | 特洛伊（十年封锁） | 切断补给线，等待敌方资源耗尽 |
| 计谋/内应 | 木马计、安条克内应 | 间谍/颠覆单位，从内部打开城门 |
| 引水/改道 | 居鲁士破巴比伦 | 利用地形/水道改变攻防条件 |
| 诱敌出城 | 各种佯攻 | 假装撤退，引诱守军出城野战 |
| 救援/反包围 | 斯大林格勒天王星行动 | 守城方的援军从外部包围围城方 |
| 谈判/劝降 | 多次出现 | 心理战/劝降机制，降低敌方士气后和平接管 |

### 3.3 守城方的生存策略

1. **坚壁清野**：撤退前烧毁城外资源，让围城者无物可征
2. **出击骚扰**：守城方主动出击，破坏攻城器械、切断围城者补给
3. **多路补给**：不依赖单一补给线，建立秘密补给通道
4. **消耗对方意志**：让围城者相信"这座城永远打不下来"
5. **等待援军**：核心策略——坚持到援军到来

## 四、后勤战役：战争的隐形支柱

### 4.1 后勤的核心要素

> "外行谈战术，内行谈后勤。"——奥马尔·布拉德利

**五大后勤要素：**
1. **补给（Supply）**：粮食、弹药、燃料、装备
2. **运输（Transportation）**：道路、河流、铁路、空运
3. **医疗（Medical）**：伤员救治、卫生防疫
4. **维修（Maintenance）**：装备维修、设施维护
5. **人事（Personnel）**：兵员补充、轮换、休整

### 4.2 历史上的后勤决定性战役

**迦太基的后勤优势与劣势（布匿战争）**
- 汉尼拔翻越阿尔卑斯山（公元前218年）：38头战象和数万军队翻越雪山，损失过半但出其不意
- 坎尼会战（公元前216年）：汉尼拔以少胜多，但无法乘胜攻取罗马——因为缺乏攻城器械和补给线
- 最终罗马人通过切断迦太基的补给线（西庇阿攻击西班牙和北非）赢得战争
- **核心教训**：战术天才无法弥补战略后勤的劣势；深入敌境的军队如果没有稳定补给线，最终会被消耗

**蒙古帝国的后勤革命（13世纪）**
- 蒙古军队的"随行补给"：每个士兵带多匹马，马奶/马血作为食物，不需要漫长的补给线
- 这使蒙古军队获得了前所未有的机动性和战略纵深
- 但在攻城战中（如钓鱼城、襄阳），蒙古人也需要建立正规的补给线和攻城器械
- **核心教训**：不同的后勤模式决定了军队的战略风格——"游牧式后勤"适合机动野战，"定居式后勤"适合攻城和持久作战
- **游戏映射**：不同阵营有不同的后勤模式——机动型阵营（随队补给，高机动但攻城弱）vs 定居型阵营（补给线，低机动但攻城强）

**拿破仑的后勤失败（1812年征俄）**
- 拿破仑的大军团（Grande Armée）60万人入侵俄国
- 俄军坚壁清野，法军补给线拉得过长
- 莫斯科撤退时，零下30度的严寒和饥饿使法军几乎全军覆没
- **核心教训**：补给线长度有极限；敌方的坚壁清野可以使最强大的军队崩溃
- **游戏映射**：军队离基地越远，补给效率越低；敌方可以使用"焦土政策"

**二战中的后勤决定性**
- 北非战场：隆美尔的非洲军团因补给不足（地中海补给线被英军切断）而失败
- 太平洋战场：美军的"岛屿跳岛"战术和潜艇战切断日本的资源运输线
- 柏林战役：苏军的后勤优势（大量卡车和物资）使其能维持大规模进攻
- **核心教训**：现代战争中，制空权/制海权本质上是后勤线的控制权

## 五、后勤战的游戏化设计

### 5.1 补给线系统

**核心机制：**
- 建筑/单位需要从主基地获得补给
- 补给线可以被敌方切断（侦察单位、游击队、空袭）
- 切断补给线后，前线单位效率下降（攻击/防御/移动速度降低），持续切断会导致单位掉血/崩溃

**设计变体：**
- **陆地补给线**：道路/补给车，可被伏击
- **海上补给线**：运输船，可被潜艇/海军拦截
- **空中补给**：运输机，可被战斗机拦截，但不受地形影响
- **随队补给**：机动型阵营的特殊能力，不需要补给线但有容量限制

### 5.2 资源类型的扩展

传统RTS通常只有2-3种资源（金/木/油），后勤战可以扩展为：
- **粮食**：维持人口和单位士气
- **弹药**：维持远程单位和攻城武器的攻击
- **燃料**：维持机械化单位的移动
- **医疗**：维持单位的持续作战能力（自动回血）
- **备件**：维持高级单位的维修

不同资源的短缺产生不同效果：
- 缺粮：士气下降，单位可能哗变
- 缺弹：远程单位无法攻击
- 缺油：机械化单位无法移动
- 缺医疗：单位无法自动恢复，伤员累积

### 5.3 围城战模式

**特殊游戏模式：围城战**
- 一方守城（有城墙/防御工事/有限资源），一方攻城
- 守城方目标：坚持N分钟/等到援军
- 攻城方目标：在时间内破城/消耗守城方资源
- 地图设计：城内资源有限，城外资源丰富但攻城方需要保护补给线
- 特殊机制：
  - 守城方可以出击骚扰攻城方补给线
  - 攻城方可以建造攻城器械（需要时间和资源）
  - 双方都有"士气条"，士气归零则失败
  - 天气/季节影响（冬季围城对双方都更残酷）

### 5.4 焦土政策

- 撤退方可以烧毁/破坏资源点，使其无法被敌方利用
- 代价：需要时间和操作，且可能影响未来的反攻
- 战略价值：让深入的敌方失去补给来源

## 六、与凌栖项目的关联

### 对战策的直接价值
- **补给线系统**：为RTS增加战略深度，不仅仅是暴兵A过去
- **围城战模式**：作为特殊对战模式，增加游戏多样性
- **多资源系统**：扩展传统RTS的资源维度，每种资源短缺有不同效果
- **后勤阵营差异化**：不同阵营有不同的后勤模式（机动vs定居），产生不同的战略风格

### 对Ember灵魂引擎的启示
- **消耗与意志**：围城战的"意志消耗"可以迁移到灵魂的心理模拟——灵魂在持续压力下也会"消耗"（疲劳、绝望、崩溃）
- **补给线与认知资源**：灵魂的认知资源（注意力、记忆力）也有"补给线"——睡眠/休息是认知的补给，持续缺乏会导致认知能力下降

### 对Arboreus世界引擎的启示
- **后勤模拟**：世界引擎中的文明/聚落模拟需要后勤系统——聚落的食物、水、物资的生产和运输
- **围城事件**：世界模拟中可以自然发生围城事件——两个聚落冲突时，一方会围困另一方

## 七、跨领域联想

- **商业竞争**：供应链管理是商业的"后勤战"，切断对方供应链是竞争手段
- **生物学**：生物体的循环系统就是"补给线"，切断血液供应导致器官坏死
- **网络安全**：DDoS攻击就是"围城战"——用流量淹没服务器，使其无法提供服务
- **心理学**："焦土政策"对应心理防御中的"自我破坏"——在被攻击前先破坏自己的资源，使攻击者无法利用
